# Pompom Throw Study

Exact copy of the published Claude artifact, unchanged.

- Source: `index.html` (single self-contained file: HTML, CSS, JS and fiber data inline)
- Assets: none. No images, fonts, or external scripts.
- Dependencies: none. No build step, no install.
- Run: open `index.html` in a browser, or `python3 -m http.server 8000` in this folder and visit http://localhost:8000
- Browser APIs: Canvas 2D, Pointer Events, Web Audio (sound starts after the first touch).
